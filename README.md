# Examen_Final_BaseDeDatos

## Descripcion:

Una base de datos que permite gestionar eficientemente los productos, combos, pedidos y clientes de una pizzería. Se buca poder almacenar información sobre pizzas, panzarottis, otros productos no elaborados (bebidas, postres, etc.), adiciones y el menú disponible. Ademas de permitir que los clientes hagan pedidos, ya sean adomicilio o para comer en el lugar.
